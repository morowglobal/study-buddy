# Course info: Intro to JavaScript

## Teacher and class times

Our teacher is Ms. Rivera. Class is on Tuesday and Thursday, 4 to 6 pm, in Lab 2. Office hours are Wednesday 3 to 4 pm on Discord, in the #help channel. She answers questions there faster than by email.

## Grading

- Final project: 40%
- Weekly quizzes: 30% (the lowest quiz score is dropped)
- Homework: 20%
- Participation: 10%

Late homework loses 10% per day. After 3 days it is not accepted.

## Final project

The final project is due Friday of week 8, before midnight. It must be a small web app that uses fetch with at least one free public API, has no frameworks (plain HTML, CSS and JavaScript only), and is deployed online with a working link. We present it in class in week 9, 5 minutes each, and we must explain one bug we fixed.

## Class rules for code

Ms. Rivera's rules: never use var, always use let or const. Always use === instead of ==. Every function needs a name that says what it does, like calculateTotal, not doStuff. Comment the why, not the what.
